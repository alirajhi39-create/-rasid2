# رَصْد — نظام إدارة ورصد درجات الطلاب

نظام ويب متكامل باللغة العربية (RTL) لإدارة ورصد درجات الطلاب وفق **لائحة تقويم الطالب في التعليم العام السعودي**، ومتوافق مع كشوف **نظام نور**.
جاهز للنشر الفوري على **Vercel** مع الربط التلقائي بقاعدة بيانات **Neon PostgreSQL**.

## 2) المكتبات المستخدمة (`package.json`)

| المكتبة | الغرض |
|---|---|
| `next` (16.x) | إطار العمل — App Router |
| `react` / `react-dom` (19.x) | واجهة المستخدم |
| `drizzle-orm` + `pg` | ORM والاتصال بـ PostgreSQL |
| `@neondatabase/serverless` | در HTTP السحابي لدوال Vercel Serverless |
| `bcryptjs` | تشفير كلمة مرور المعلم |
| `jose` | توقيع جلسات JWT (متوافق مع Edge) |
| `xlsx` (SheetJS) | قراءة ملفات Excel واستيرادها + تصدير .xlsx |
| `tailwindcss` v4 + `@tailwindcss/postcss` | التصميم المتجاوب RTL |
| `typescript` | الأنواع الثابتة |

**لا توجد أي بيانات دخول افتراضية ولا تلميحات لكلمات المرور في أي مكان.**
أول معلم يفتح صفحة الدخول وينشئ حسابه يحصل تلقائياً على صلاحية **مدير النظام**، ثم يمكن لأي معلم
آخر إنشاء حسابه الخاص بنفسه من تبويب «حساب جديد».

## 3) خطوات النشر السريعة (Vercel + Neon)

### أ) عبر واجهة Vercel

1. **ارفع المشروع إلى GitHub.**
2. في لوحة Vercel: **Add New → Project** → اختر المستودع → **Import**.
3. من تبويب **Storage** في المشروع → اختر **Neon Postgres** (Marketplace) → **Connect**.
   *ينشئ Vercel تلقائياً متغير `DATABASE_URL` ويربطه بجميع البيئات.*
4. اذهب إلى **Settings → Environment Variables** وأضف:
   | المتغير | القيمة |
   |---|---|
   | `AUTH_SECRET` | نص عشوائي طويل (٣٢ حرفاً على الأقل) |
5. اضغط **Deploy**.
6. بعد النشر، افتح التطبيق — ستُنشأ الجداول **تلقائياً** عند أول زيارة لصفحة الدخول
   (يمكن أيضاً استدعاء `https://your-app.vercel.app/api/init-db` يدوياً).
7. من صفحة الدخول اختر **«حساب جديد»** وأدخل اسمك واسم مستخدم وكلمة مرور خاصة بك —
   ستحصل تلقائياً على صلاحية مدير النظام. يمكن لبقية المعلمين إنشاء حساباتهم بنفس الطريقة.

### ب) عبر Vercel CLI

```bash
npm i -g vercel
vercel link
vercel env add AUTH_SECRET          # الصق قيمة عشوائية
vercel --prod
```

### ج) ربط Neon يدوياً (اختياري)

```bash
# من لوحة Neon: Projects → Connection string
vercel env add DATABASE_URL production
# الصق: postgresql://user:pass@ep-xxx-pooler.region.aws.neon.tech/dbname?sslmode=require
```

### د) التشغيل محلياً

```bash
cp .env.example .env      # ثم عدّل DATABASE_URL
npm install
npm run dev               # http://localhost:3000
```

> **ملاحظة:** لا حاجة لتنفيذ أي أوامر SQL يدوياً — المسار `/api/init-db` ينفّذ
> `CREATE TABLE IF NOT EXISTS` لجميع الجداول ويزرع البيانات الأولية.

## 4) المزايا الوظيفية

- **تعدد المعلمين:** أي معلم يستطيع إنشاء حسابه الخاص بنفسه من تبويب «حساب جديد» في صفحة الدخول (اسم + اسم مستخدم + كلمة مرور خاصة به). أول حساب يُنشأ يحصل على صلاحية **مدير النظام**.
- **عزل البيانات:** كل معلم يرى **فصوله وطلابه ومواده ودرجاته فقط** — التحقق من الملكية مطبَّق في كل مسار API وصفحات الطباعة (`src/lib/ownership.ts`).
- **بيانات المدرسة المشتركة:** اسم المدرسة، إدارة التعليم، العام الدراسي، الفصل الدراسي، واسم مدير المدرسة — تُدخل عند التسجيل أو من الإعدادات وتظهر في كل الكشوف. أما **اسم المعلم** في الترويسة فيُؤخذ تلقائياً من حساب من يرصد.
- **إدارة الحسابات (للمدير):** إضافة معلمين، عرض عدد فصولهم وطلابهم، وحذف الحساب مع كل بياناته.
- **الحماية:** كلمة مرور مشفّرة (bcrypt) لا تُعرض ولا تُسترجع في أي مكان، جلسة JWT في كوكي `httpOnly` لمدة ٣٠ يوماً، وحماية المسارات عبر `middleware`.
- **الطلاب والفصول:** إضافة/تعديل/حذف/نقل بين الفصول، ترقيم تلقائي، بحث فوري، واستيراد دفعة واحدة من `.xlsx`/`.xls`/`.csv` أو **اللصق المباشر من كشوف نور**.
- **ربط المادة بالصف:** كل مادة مرتبطة بفصل دراسي واحد فقط (فريد على مستوى `classroom_id + name`) ولا تظهر في قوائم الفصول الأخرى، مع تحقق من الملكية في كل مسار.
- **الفصلان الدراسيان والفترتان:** العام الدراسي **فصلان رأسيان فقط** (الأول والثاني)، ولكل فصل دراسي **فترتان** (الفترة الأولى والفترة الثانية):
  - تُوزَّع خانات الدرجات على الفترتين، ولكل فترة مجموعها الجزئي
  - درجة مستقلة لكل (طالب × مادة × فصل دراسي) — فهرس فريد `grades(student_id, subject_id, semester)`
  - يُحسب تلقائياً: **مجموع كل فصل** + **مجموع الفصلين (السنوي)** + **المتوسط** بين الفصلين
  - القوالب الجاهزة توزّع الدرجات على الفترتين تلقائياً
- **المواد وتوزيع الدرجات:** بنّاء مرن — افتح/أغلق أي خانة، حدّد الدرجة العظمى والفترة والمجموعة لكل خانة، واختر من قوالب جاهزة:
  - ابتدائي (١–٣): تقويم مستمر ١٠٠ درجة (٤٠ + ٦٠ على الفترتين)
  - ابتدائي (٤–٦) / متوسط: أعمال السنة ٦٠ + نهائي ٤٠
  - ثانوي: أعمال السنة ٦٠ + تحريري ٣٠ + عملي/شفهي ١٠
- **الرصد:** جدول سريع يدعم **التنقل بالأسهم** و**Enter**، حساب المجموع والتقدير (ممتاز/جيد جداً/جيد/مقبول/ضعيف) فورياً، **حفظ تلقائي** مع مؤشر «محفوظ في السحابة»، وتنبيه بصري عند تجاوز الدرجة العظمى أو الرسوب.
- **التقارير:** كشف الفصل الكامل (A4 بالعرض)، إشعارات فردية (A4 بالطول)، و**كشف سنوي لمجموع الفصلين والمتوسط** — جميعها بترويسة المملكة العربية السعودية / وزارة التعليم / إدارة التعليم / المدرسة مع **شعار وزارة التعليم**، وتوقيعَي **معلم المادة** و**مدير المدرسة** فقط، عبر `@media print` نظيف.
- **التصدير:** ملف `.xlsx` بثلاث أوراق (كشف الدرجات بفصليه وفترتيه مع مجموع الفصلين والمتوسط، توزيع الدرجات، الإحصاء) بترتيب أعمدة مناسب للاستيراد في نظام نور.
- **التصميم:** عربي RTL بالكامل بخط Cairo/Tajawal، متجاوب مع الكمبيوتر والجوال والآيباد.

## 5) مسارات الـ API

| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/health` | GET | فحص اتصال قاعدة البيانات |
| `/api/init-db` | GET / POST | **إنشاء الجداول تلقائياً + المستخدم الافتراضي** |
| `/api/auth/register` | POST | **إنشاء حساب معلم جديد** (أول حساب = مدير النظام) |
| `/api/auth/login` | POST | تسجيل الدخول |
| `/api/auth/logout` | POST | تسجيل الخروج |
| `/api/auth/me` | GET | بيانات الجلسة الحالية |
| `/api/auth/password` | PUT | تعديل الاسم / اسم المستخدم / كلمة المرور |
| `/api/settings` | GET / PUT | بيانات المدرسة والترويسة |
| `/api/classrooms` | GET / POST | قائمة/إضافة الفصول |
| `/api/classrooms/[id]` | PUT / DELETE | تعديل/حذف فصل |
| `/api/students` | GET / POST | بحث/إضافة طالب |
| `/api/students/[id]` | PUT / DELETE | تعديل/حذف/نقل طالب |
| `/api/students/import` | POST | استيراد دفعة (Excel أو لصق) |
| `/api/subjects` | GET / POST | قائمة/إضافة مادة مع توزيعها |
| `/api/subjects/[id]` | PUT / DELETE | تعديل/حذف مادة |
| `/api/grades` | GET / PUT | قراءة كشف (بفصل دراسي) / **حفظ تلقائي** |
| `/api/grades/summary` | GET | **مجموع الفصلين والمتوسط** |
| `/api/export` | GET | تنزيل `.xlsx` لنظام نور |
| `/api/teachers` | GET / POST / PUT / DELETE | إدارة حسابات المعلمين (المدير فقط) |
